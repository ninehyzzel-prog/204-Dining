# 204 DINING — iPad Landscape Digital Menu System

> **미쉐린 3스타급 프라이빗 파인다이닝의 경험을 아이패드에 구현한 디지털 메뉴 시스템**

---

## 🌟 핵심 구현 기능

1. **실시간 3D 360° 인터랙티브 음식 뷰어 (Three.js WebGL)**
   - 상세 화면(Screen 05)에서 즉시 3D 접시와 음식이 렌더링되며, 손가락 터치 드래그로 360도 회전, 핀치 줌, 관성 댐핑 지원.
   - 스튜디오 파인다이닝 조명(Key Spotlight, Warm Fill, Cool Rim Light) 및 부드러운 테이블 접촉 그림자(Soft Shadow) 구현.
   - 정면(30°), 히어로(45°), 탑뷰(80°), 디테일 클로즈업 등 앵글 프리셋 버튼 지원.
   - **사용자 GLB 모델 자동 감지**: `assets/models/dish-[1~6].glb` 파일이 존재할 경우 실사 3D 모델을 즉시 로드하며, 모델이 없을 경우 미식 플레이팅의 절차적 3D 모델(한우 안심, 관자, 푸아그라 등)이 표시됩니다.

2. **자연스러운 인간형 AI 음성 나레이션 (Azure Neural TTS)**
   - 기계음이 아닌, 파인다이닝 호스트/지배인의 차분하고 품격 있는 목소리(`ko-KR-InJoonNeural`) 탑재.
   - 웰컴 인사, 셰프 철학 소개, 메뉴 카테고리, 6종의 각 요리별 도슨트 설명, 주문 완료 감사 멘트 수록.
   - 상단 헤더의 `[VOICE: ON/OFF]` 버튼으로 자유롭게 제어 가능.
   - 상세 화면에서는 `[▶ 음성 나레이션 듣기 / 일시정지]` 전용 도슨트 버튼 제공.
   - **iOS Safari 오디오 정책 최적화**: 웰컴 화면 터치 시 브라우저 오디오 컨텍스트가 자동 언락되며, 서버에서 HTTP 206 Partial Content Range 스트리밍을 지원합니다.

3. **아이패드 전용 가로형 적응형 핏 (Adaptive Canvas) & PWA**
   - 1600 × 1200px (4:3) 기준 레이아웃이 10.2", 10.9", 11", 12.9" 등 다양한 아이패드 및 태블릿 화면에 레터박스 왜곡 없이 완벽히 중앙 정렬 스케일링.
   - Safari [홈 화면에 추가] 시 상단 주소창이 사라지고 독립 실행형 네이티브 앱(PWA) 모드로 동작.

4. **완전한 6화면 인터랙션 & 주문 프로세스**
   - 01 Welcome → 02 Meet the Chef → 03 Menu Index → 04 Today's Table → 05 Dish 3D Detail → 06 Order Complete
   - 카테고리 필터링 (ALL DISHES, SIGNATURE, STARTERS, MAINS, DESSERTS).
   - 수량 선택 및 장바구니 담기, 주문 번호 및 실제 담은 요리 목록이 출력되는 주문 확인서.

## 🚀 빠른 시작 가이드

### 1. PC에서 로컬 서버 실행
프로젝트 루트 폴더에서:
```bash
# batch 파일 더블 클릭 또는
start.bat

# 또는 커맨드라인에서
node server.js
```

실행 시 터미널에 다음과 같이 아이패드 접속 주소가 표시됩니다:
```
===============================================================
   ✦ 204 DINING — Private Fine Dining iPad Menu Server ✦
===============================================================
  [PC 로컬 확인]:   http://localhost:3000
  [아이패드 접속]:  http://192.168.X.X:3000
---------------------------------------------------------------
```

### 2. 아이패드에서 실행하기
1. PC와 아이패드가 **동일한 Wi-Fi 공유기**에 연결되어 있는지 확인합니다.
2. 아이패드 **Safari** 브라우저를 열고 터미널에 표시된 `http://192.168.X.X:3000` 으로 접속합니다.
3. Safari 상단/하단의 **[공유 버튼 (네모에 화살표)]** → **[홈 화면에 추가]**를 누릅니다.
4. 홈 화면에 생성된 `204 DINING` 아이콘을 누르면 주소창 없는 전체화면 파인다이닝 메뉴판이 실행됩니다.

## 🥩 실제 음식 사진을 3D 모델(GLB)로 변환하여 적용하는 법

직접 조리한 집들이 음식 사진을 실사 3D 모델로 띄우려면 다음 파이프라인을 추천합니다:

1. **스캔/변환 앱 사용 (가장 추천)**:
   - **Polycam** 또는 **Kiri Engine** (아이폰 / 안드로이드 앱)
   - 접시를 밝은 조명 아래 두고 360도를 돌며 30~50장의 사진을 촬영하거나 비디오 스캔 모드를 사용합니다.
   - 클라우드 처리 후 **`.glb` 형식**으로 다운로드합니다.
   - 대안: 사진 1~2장으로 빠른 생성을 원할 경우 **Tripo3D** 또는 **Meshy.ai** 웹사이트 이용.

2. **파일 저장 경로**:
   - 다운로드한 `.glb` 파일의 이름을 요리 번호에 맞게 변경하여 아래 폴더에 넣습니다:
     - 북해도 관자: `assets/models/dish-1.glb`
     - 푸아그라: `assets/models/dish-2.glb`
     - 메인 랍스터: `assets/models/dish-3.glb`
     - 한우 안심: `assets/models/dish-4.glb`
     - 트러플 아뇰로티: `assets/models/dish-5.glb`
     - 바닐라 앤 페어: `assets/models/dish-6.glb`
3. 파일을 넣고 상세 화면에 들어가면 웹뷰어가 자동으로 해당 3D 모델을 감지하여 렌더링합니다.

## 🎙️ 음성 멘트 수정 및 재생성 방법

음성 나레이션 문구를 바꾸거나 새로운 멘트를 추가하려면:
1. 루트의 `generate_audio.py` 파일을 엽니다.
2. `AUDIOS` 딕셔너리의 텍스트를 원하는 내용(예: 손님 이름 환영 멘트 등)으로 수정합니다.
3. 실행합니다:
   ```bash
   python generate_audio.py
   ```
4. `assets/audio/` 폴더에 스튜디오 품질의 새 오디오 파일이 즉시 덮어씌워집니다.
